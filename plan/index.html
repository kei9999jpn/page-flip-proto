尽きぬ書 本番仕様

ここまでで決まったことと、体験の流れ。第2稿 2026-09-03 夜。今夜の一から作り直し（売り物レベル）の設計図として使う。

1. 決まったこと（確定）

本のコンセプト

集めた言葉を全部綴じた本。栞がなければ開くたび並びが変わり、栞を挟めば固定。言葉が増えるほど分厚くなる。総数は見せず「何枚目」だけ見せる。

背景

最初に作った書斎の絵（暗い線画調）を使う。油彩調はやめ。時間帯で変わる仕掛けは作らない。読む時だけ暗く沈む。

書斎の主

KEI制作の人物モデルを待つ（今は白い素体）。顔のドアップ・呼吸・頷き・手上げ。セリフは枠なしの金の字幕（装甲明朝は必須ではない）。

本の3D

開閉と「開いて吸い込まれる」演出はそのまま継承。革・金箔紋章・古び・擦れはテクスチャで描く（3Dで作り込まない）。分厚く古びた古代の書、重厚感。

音

人間と本の画面はBGMなし、雨と暖炉の環境音だけ。読む画面の最初のタッチから音楽。虫の声・爆ぜ音は使わない。

読み方

ランダム／栞の続き（挟んだら固定）／お気に入りだけ／新しく開き直す。テーマ読みは保留。

UI

今のは安っぽい。差の大きい3案を作ってKEIが選ぶ。ロゴマーク（葉と眼）は常にどこかに。

お金・分類・人物

お金は保留（構造だけ残す）。テーマ分けは保留。人物モデルはKEIが制作中。

2. 体験の流れ（新）

画面を3つに分けない。1つの画面の中で、人間 → 本 → 本の中、へ切れ目なく進む。参考はバイオハザードのアイテム取得画面。

一
書斎の主が迎える顔のドアップ。字幕「よく来たね。」「今日はどうしたんだい？」→ 選択肢（魔法の名言の書／思考実験・占い・星座占い・エッセイ集＝準備中）。環境音のみ
二
主がフェードで消え、本が現れる「魔法の書」を選んだ瞬間、主が薄れて消える。同じ書斎の中央に、本が0%から100%へふわっと拡大して現れ、ゆっくり回り続ける（アイテム取得の見せ方）。主は画面外から一言だけボソッと言う（下の10パターンからランダム）。環境音のみ
三
本の下にボタン「読む」「詳細を読む」「お気に入りを見る」「設定」。「詳細を読む」はゲームのアイテム説明のような、分かりやすい解説パネル。閉じれば本に戻る。
四
読む → 表紙が開いて吸い込まれる今の演出をそのまま。書斎が暗く沈み、蝋燭の灯りの中で頁をめくる。右上に「◯枚目」。右下「お気に入りに登録」、左下「栞を挟む」。最初のタッチから音楽
本を選ぶたびに長いセリフを聞かされない。説明は「詳細を読む」に隔離し、主の一言は短くランダム。

3. 書斎の主の一言（本が出た時・ランダム・下書き）

「だ・である」の短い断定。教えない、押しつけない。KEIが直してよい。

  • ああ、その本か。私も暇なときによく開いている。
  • 不思議な本でね。開くたびに、中の順番が変わる。
  • それは、私が今まで集めてきた言葉を全部綴じたものだ。
  • 悩みがあるなら、めくってみるといい。答えに近いものが、必ず一つは挟まっている。
  • 昨日の一頁目は、今日はもうどこにもない。本の説明文と同じ一文。声として繰り返す
  • 気に入った頁があれば、挟んでおくといい。あとで、それだけの一冊になる。
  • 栞を挟むと、この本は姿を変えなくなる。挟まなければ、毎回別の本だ。
  • 終わりはない。ただ、日に日に分厚くなっていく。
  • 読んでも、賢くはならない。見え方が、少し変わるだけだ。
  • どこで閉じてもいい。次に開いたときには、もう別の本だから。

4. 「詳細を読む」の文面（アイテム解説・下書き）

尽きぬ書

書斎の主が集めてきた言葉を、全部まとめて綴じた本。

開くたびに頁の順番が入れ替わる。同じ順番で読めることは二度とない。言葉が増えるたびに、日に日に分厚くなっていく。

読み方　頁の右上をつまんでめくる。左へ引くと次の頁、右へ引くと前の頁。右上の数字は、今までに見た枚数。

お気に入り　気に入った頁で「お気に入りに登録」。登録した頁だけを綴じ直した、自分だけの一冊を「お気に入りを見る」で開ける。

栞　「栞を挟む」を押すと、その並びとその頁を覚える。以後は同じ並びの続きから読める。「新しく開き直す」で並びを変えると、栞は外れる。栞は一つだけ。この端末に保存される。

音　雨と暖炉の音、本を開いてからは音楽。「設定」で変えられる。

5. 見た目の基準

要素基準状態
背景最初の書斎の絵。人間〜本まで同じ。読む時は暗い版確定
本の表紙黒に近い牛革・葉と眼の金箔紋章・古び・擦れ・角の丸み、全部テクスチャで。分厚く重厚テクスチャ作り直し
灯りゆっくり滑らかに、ぼやーっと。本の上だけ明るく、縁は闇。火の粉は蝋燭から基準決定
字幕枠なし・金×黒・画面の下から2番目の高さ。書体は装甲明朝または今の雰囲気確定
ボタン・パネル差の大きい3案 → KEIが選ぶ。安っぽさを消す（革・真鍮・古紙・彫刻の質感を候補に）3案を作る
本の出現0→100%の拡大＋回転。バイオハザードのアイテム取得確定

6. 今夜の作り直し（段取り）

  1. 先に素材：本の表紙テクスチャ一式（ChatGPT／MJ）・UI3案（画像で提示）・主の一言10本と詳細文（上の下書き）。
  2. 1つのアプリとして組む：画面遷移なし。人間→本→本の中を同じページ内で切り替える。音は途切れない。キャッシュ問題も消える。
  3. 継承するもの：開いて吸い込まれる演出・めくり（コーナーピール・裏透け）・栞とお気に入りの保存形式・790枚の遅延読込・設定。
  4. 捨てるもの：3つに分かれたHTML・Wisdom Leafのロゴ表示・虫の声と爆ぜ音・羊皮紙UI・時間帯の仕掛け。
  5. 検証：KEIのiPhoneで、人間→本→読む→栞→戻る、を一周。
