書斎 作り直し計画書

初稿 2026-09-03 アラレ。今のプロトタイプ（v5）を土台に、素材を先に揃えてから Fable 5.1 で一から組み直すための地図。KEIと一緒に書き換えていく。

1. 何を作るか

KEIが集めた言葉を全部綴じた「尽きぬ書」を、暖炉のある賢者の書斎で読む縦型Web体験。栞を挟まなければ開くたび並びが変わり、栞を挟めば固まる。言葉が増えるほど本は分厚くなる。

目標との接続：TikTokのフォロワー（50万人目標）を「本」に流し、書斎という場所を持つ。収益化は保留だが、会員制にできる構造は最初から残す。

2. 体験の流れ（確定）

一
書斎の主に会う顔のドアップ。字幕風のセリフ「よく来たね。」「今日はどうしたんだい？」→ 選ぶ →「本を見に行く」。BGMなし、雨と暖炉の音だけ。
二
本と向き合う同じ書斎の中に3Dの本が浮く。回して眺める。下に小さなボタン「読み方を選ぶ／説明／設定」。BGMなし。
三
本の中に入る表紙が開いて光に吸い込まれる（この演出は必ず残す）。書斎は暗く沈み、蝋燭の灯りの中で頁をめくる。最初のタッチから音楽。

3. 品質を最大まで上げる項目

「今」→「目指す姿」。素材が要るものは先に作る。

領域今目指す姿先に要る素材状態
背景ChatGPT1枚。AI感が強い油彩の質感。人間〜本まで同じ画、読む時は暗い版。時間帯で灯りが変わる差分もMJ3案＋ChatGPT3案から選ぶ→選んだ1枚を高解像度化＋暗い版候補生成中
書斎の主白い素体の仮置きKEI制作の人物モデル。呼吸・瞬き・口の動き・手のジェスチャー。顔のドアップに耐える質感人物モデル（glb）。骨の名前を今と合わせるKEI制作中
本の3DBlender自作。革・金箔紋章・背表紙埋め済み牛革の質感（法線マップ・粗さマップ）・小口の金付け・革の擦れ・角の丸み。開閉は今の仕組みを継承表紙テクスチャ一式（色・法線・粗さ）を写真かChatGPTで作り直し次
開く演出表紙が開き光に吸い込まれるそのまま採用。光の粒と音を作り込む吸い込みSE 1本確定
めくり自作canvas。裏透け・追従紙の厚み・端の擦れ・影の落ち方を詰める。790枚を軽く（先読み済み）なし（実装）継承

音YouTube抽出の雨＋暖炉／BGM半分場面ごとに層を分ける。人間＝雨・暖炉／本＝＋紙の擦れ／読書＝＋BGM。めくり音を数種類ランダムめくり音3〜5種、吸い込みSE、BGM1〜2曲（Suno）素材作り
文字・UI装甲明朝の金字幕／茶の板ボタン字幕は装甲明朝で統一。ボタン・パネルは3案作ってKEIが選ぶ。ロゴマークは常にどこかにUIパターン3案（画像で提示）KEIが選ぶ
言葉790枚の画像全部入り。テーマ分けは保留。増える前提でコピー1本で追加できる導線追加手順書（済）済
読み方ランダム／栞／お気に入りそのまま。栞は1つ。テーマ読みは保留なし確定

土台3つのHTMLが別々。設定は共有1つのアプリとして組む（画面切替で音が途切れない・キャッシュ問題が消える）なし（実装）組み直し時
お金なし保留。会員ページを後から差し込める構造だけ残す—保留

4. 先に揃える素材（順番どおり）

  • 書斎の背景 1枚を決めるMJ3案＋ChatGPT3案 → KEIが選ぶ → 高解像度化 → 暗い版を作る
  • 本の表紙テクスチャ一式色・法線・粗さ。牛革＋金箔紋章。今の参照画像を元に
  • 人物モデルKEI制作。骨の名前は Torso / Head / ArmL / ArmR / HandL / HandR に合わせると今の動きがそのまま効く
  • UIパターン3案ボタン・パネル・設定画面。画像で並べてKEIが選ぶ
  • 音めくり音3〜5種／吸い込みSE／BGM（Suno）／雨・暖炉は今のを継続
  • 火の粉の実写素材（任意）透過WebM。合わなければ今の描画を磨く
  • 説明文・セリフの原稿「この本の説明」と書斎の主のセリフ集。KEIの声で

5. 作り直しの段取り

  1. 素材（1〜2週間） 上の7つを揃える。KEIの選択が要るのは背景・UI・人物。
  2. 骨組み（2日） 1つのアプリとして、画面の切替・音の層・設定・栞・お気に入りを先に組む。見た目は後。
  3. 画面（3日） 書斎の主 → 本 → 読書、の順に見た目を入れる。1画面ずつKEI確認。
  4. 演出（2日） 開く演出・灯り・火の粉・めくりの質感。ここで一番時間を使う。
  5. 検証（1日） KEIのiPhone・古い端末・回線が弱い時。落ちない・重くない・音が途切れない。
今のプロトタイプは「答え合わせ用」として残す。作り直しは別フォルダで進め、揃ってから差し替える。

6. KEIに決めてほしいこと

1. 背景：MJ3案とChatGPT3案のどれか。または「もう1周」。

2. UI：3案を出すので選ぶ（金×黒の字幕は確定として）。

3. 人物：いつ頃できそうか。仮の素体のまま進めてよいか。

4. 音：BGMはSunoで新しく作るか、今の曲を続けるか。

5. 段取り：上の順番でよいか。先に見たい画面があるか。

7. 保留にしたもの

  • お金の受け取り方（FANBOX/note → Stripe の2段階案は出してある）
  • テーマで読む（790枚の分類）
  • 思考実験・占い・星座占い・エッセイ集の中身
